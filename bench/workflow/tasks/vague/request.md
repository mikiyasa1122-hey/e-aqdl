# 依頼

チームでメモを共有する Python のライブラリ（notes パッケージ）を作ってください。SQLite に保存します。

- 組織ごとにメモを分けます。他の組織のメモは見えないようにしてください。自分だけの非公開メモも作れます。
- メモにはタグを付けられて、一覧や検索ができます。
- 作った人と、その組織の管理者が、メモを直したり消したりできます。同時に編集しても、人の変更を消さないようにしてください。
- 管理者は、辞めた人のメモを別の人に引き継げます。
- 管理者は操作の記録（監査ログ）を出せます。API キーが丸見えにならないようにしてください。
- 書き込みが多すぎる人を制限する仕組みと、期限付きの共有リンクも要ります。
- 安全に、壊れにくく作ってください。

呼び出し方（関数の名前・引数・戻り値・テスト用の差し込み口）は `docs/contract.md` に決めてあります。細かい規則で決まっていない
ところは、妥当なものを決めて進めてください。`notes/db.py` と `notes/errors.py` は用意済みで、変えないでください。
テストも作ってください（`python3 -m unittest discover -s tests -t .`）。Python 3 の標準ライブラリだけを使います。
