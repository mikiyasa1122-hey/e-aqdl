# 依頼者の意図（実験05・作り手には見せない）

お題: 既存のメモ共有 API の仕様を2点変更する。(1) 管理者も他人のメモの内容を編集できる。(2) タイトルの上限を100文字から50文字に。

依頼者が考えていること（聞かれたときだけ答える）:
- 管理者が他人のメモを編集できるのは、公開・非公開どちらのメモも。公開範囲（非公開の切り替え）も変えてよい。
- 管理者が他人のメモを編集したら、あとで分かるようにしたい。メモに「最後に編集した人」と「その日時」を残して、取得したときに見えるようにしてほしい。
- すでに保存されている51文字以上のタイトルのメモは、そのまま残してほしい（切り詰めない・消さない）。そのメモの本文だけを直すことはできるようにしてほしい。タイトルを変えるときは50文字以内にしてもらえばよい。
- 変更しない部分（メンバーは他人のメモを編集できない、非公開、ゴミ箱、検索、自己登録なし）は今のまま。
- そのほかの点は「お任せします」。
