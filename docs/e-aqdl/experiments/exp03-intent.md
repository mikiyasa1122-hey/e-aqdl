# 依頼者の本当の意図（実験03・作り手には見せない）

お題（作り手に渡す文）: 「チームで使うメモ共有の Web API を Python で作ってください。メンバーは自分のメモを書けて、管理者は全員のメモを管理できるようにしたいです。」

依頼者が頭の中で考えていること:

- I1 共有: メモは「チーム内公開」が既定。メンバーは他のメンバーのメモを一覧・取得で読める（書き換えはできない）。
- I2 非公開: 本人はメモを「非公開」にできる。非公開のメモは本人と管理者だけが見られる。他のメンバーには存在も見えない。
- I3 メンバーの権限: メンバーは自分のメモだけを作成・更新・削除できる。
- I4 管理者の権限: 管理者は全員のメモ（非公開も含む）を閲覧・削除できる。ただし他人のメモの内容は編集できない（勝手に書き換えるのは困る）。
- I5 利用者の作り方: 利用者は管理者が API で作る。自己登録はさせない（社外の人が入れると困る）。最初の管理者は、環境変数か起動用のコマンドで作れればよい。
- I6 ゴミ箱: 削除したメモは通常の一覧・取得からは消えるが、管理者は削除済みのメモを一覧でき、元に戻せる（誤って消したときのため）。
- I7 中身: メモはタイトル（必須、100文字以内）と本文（10000文字以内）。
- I8 検索: 一覧はキーワード（タイトル・本文の部分一致）で絞り込める。

上に書いていないこと（技術スタック、トークンの方式、ページングの有無など）は「お任せ」。
