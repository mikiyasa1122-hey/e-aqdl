# 決まった返答（すべての条件で同じ規則で返す）

ターンが終わって作業が止まったとき、最後の報告の内容に応じて次の順に判定し、最初に当てはまった返答を送る。

| 状況（最後の報告に含まれるもの） | 返答 |
|---|---|
| Memory の利用範囲を聞いている（E-AQDL のみ） | ③: 「Memory を使わない」 ④: 「共通 Memory も使う（承認 MEMSCOPE-xxxxxxxx）」（ID は報告から写す） |
| 仕様の承認を求めている（「承認 SPEC-…」がある） | 「承認 SPEC-xxxxxxxx」（ID は報告から写す） |
| 質問がある（選択肢・推奨案がある） | 「すべて推奨案で進めてください」 |
| Memory の保存先を聞いている（E-AQDL のみ） | 「プロジェクト内だけに保存」 |
| gh・GitHub・CI・PR について聞いている | 「GitHub への公開と PR は不要です。ローカルで完了としてください」 |
| 上のどれでもなく、完了と報告している | 終了 |
| それ以外 | 「続けてください」 |

- 返答は最大 10 回。超えたら終了し、その時点の成果物で評価する
- 人が確かめる検証（VERIFY-…）を求められたら「確認できません。自動の検証で判断してください」
